# Decoy discrimination and the protected emitter's direction

**Status:** host models and simulations only. No synthesis, no bitstream, no
hardware measurement is claimed anywhere in this document. The single hardware
step this document prepares is gate **G7** in
[`GATES_RUNBOOK.md`](../GATES_RUNBOOK.md).

**Question.** One emitter at 2.5 GHz matters; the rest of the scene is decoys.
Two things have to be produced, not one:

1. **which** of the received signals is the protected emitter;
2. the **direction** of that emitter, still correct with the decoys in the band.

**Evidence.** Every number below is generated by a script in this repository and
written to `docs/evidence/2026-11-06-phase-interf/`:

| Script | Evidence | Sections of this document |
|---|---|---|
| `scripts/decoy_discrimination.py` | `decoy_discrimination.txt` | 3, 4, 5, 6 |
| `scripts/radar_decoys.py` | `radar_decoys.txt` | 7 |
| `scripts/radar_decoys.py --replay` | gate G7 on captured data | 11 |

`make decoy-df` and `make radar-decoy` regenerate the two evidence files. Every
row below states the case in which it **fails**; a discriminator that is claimed
without its failure case is not a discriminator.

---

## 1. Two scenarios, and why they are not the same problem

The answer depends on one property of the protected emitter: does it only
transmit, or does it transmit *and* receive?

```
                    is the protected emitter a radar?
                     (does it transmit and receive?)
                                 |
              +------------------+-------------------+
              |                                      |
             yes                                     no
   (pulsed: it must radiate to work)      (continuous emitter, CW or long burst)
              |                                      |
    §7 TIME ORDERING                        §3-§6 SPECTRUM + SPACE
    a decoy must hear the pulse before      the only differences available are
    it can repeat it, so the repeat is      carrier, angle, coherence and
    always later by >= its turnaround       kinematics
              |                                      |
    radar DOA from the leading edge         carrier  -> free (channelizer)
    decoy DOA from the tail                 angle    -> needs elements
    delay = tail length                     coherence-> needs bandwidth
              |                                      |
              +------------------+-------------------+
                                 |
                                 v
                    two directions + a confidence flag
```

A radar can be fooled by a decoy that is *co-located, co-carrier, zero-delay and
equal power* if you only look at the spectrum — that case is unsolvable in §5 and
§6, and it is called out as such. In §7 it **is** solvable, because the ordering
argument needs no spectrum at all. That is the practical value of the radar
assumption and the reason this document puts it first.

## 2. Signal model

Four-element array (2×2, 30 mm pitch, `config.mk`), per-bin narrowband model:

```
x_k(t) = s_k(t) · a(θ_s, f_k) + c·s_k(t−τ) · a(θ_d, f_k) · e^{−j2π f_k τ} + n_k(t)
         \_____ direct _____/   \____________ repeater copy ____________/

a(θ, f) = exp(−j2π f (p · u(θ)) / c)      p = element positions, u = unit vector
```

* `s_k` is the emitter's own complex amplitude in bin *k*, unknown, random.
* `τ` is the decoy's total extra delay: propagation excess plus its own
  processing turnaround.
* `c` is complex: the decoy's gain **and** an arbitrary phase from its own chain.
  A model that forces `c` to be real ties that phase to the delay and is measured
  to fail for 0.1 ns of delay error (§6.4) — that is a modelling error, not a
  hardware limit.
* The two paths are **coherent** (a repeater copies the waveform), so per bin the
  covariance is rank 1 and every subspace method sees one source.

## 3. Algorithm A — carrier clustering (free)

```
  raw 2 GS/s complex (4 ch)
        |
        v
  +-----------------------------+      +--------------------------------+
  | 1024-band channelizer       |----->| per-bin power P_k = sum|x_k|^2 |
  | 1.953 MHz bins              |      +--------------------------------+
  +-----------------------------+                    |
                                                     v
                                    +------------------------------------+
                                    | floor = 25th percentile of P       |
                                    | bins with P_k > 4 * floor          |
                                    | group contiguous bins (gap <= 2)   |
                                    +------------------------------------+
                                                     |
                                                     v
                                        one cluster per carrier
                                        -> one direction per cluster
```

Why a 25th percentile and not a median: a scene with many decoys can occupy more
than half the bins, and then the median *is* a signal. This cost one broken run,
recorded here so it is not repeated.

Measured (2×2 at 30 mm, source 2.500 GHz, 20 MHz, decoys of equal bandwidth on
their own carriers, 2.30–2.70 GHz axis, 16 trials):

| decoys on other carriers | clusters found | source azimuth | error |
|---|---|---|---|
| 0 | 1.0 | 9.976° | −0.024° |
| 1 | 2.0 | 9.988° | −0.012° |
| 3 | 4.0 | 9.991° | −0.009° |
| 6 | 7.0 | 10.020° | +0.020° |

**Result:** each decoy costs one cluster entry and **0.00°** of accuracy.
**Fails when** the decoy sits inside the source's own 1–50 MHz → §4.

## 4. Algorithm B — angle (per-bin interferometry, and MUSIC when needed)

```
  cluster bins  ->  for each bin k:
        +-------------------------------------------------------+
        | R_k = X_k^H X_k        (spectral covariance, 4x4)    |
        +-------------------------------------------------------+
                 |                              |
                 v                              v
   +----------------------------+   +----------------------------------+
   | six-baseline phase fit     |   | eigen-decomposition              |
   | phi_ab = 2pi f (b_ab . u)/c|   | signal subspace (source count)   |
   | coherence-weighted WLS -> u|   | 2-D MUSIC over az/el             |
   +----------------------------+   +----------------------------------+
        one emitter per bin              several emitters per bin
                 |                              |
                 +--------------+---------------+
                                v
                   per-bin DOA curve  theta(f)
                   (its slope and residual drive §5)
```

Measured, two **independent** 50 MHz signals at the same carrier, 10° and 25°,
per-bin 2-D MUSIC, matched-of-2 scoring (16 trials):

| array | of 2 recovered | false peaks |
|---|---|---|
| 2×2 @ 30 mm | **0.4** | 1.6 |
| 3×3 @ 30 mm | 2.0 | 0.0 |
| 4×4 @ 30 mm | 2.0 | 0.0 |

**Result:** an independent co-channel decoy is a hardware problem, not an
algorithm problem — four elements cannot hold two signals (the M−1 rule of V07
§10.2). **Fails when** the decoy is coherent with the source: rank 1, invisible
to any subspace method → §5.

## 5. Algorithm C — the coherence alarm (wobble + cepstrum)

Two statistics come out of the per-bin curve that §4 already produces. This is
the cheapest discriminator in the whole document: no extra data, no extra
hardware.

```
   theta(f) from §4
        |
        +--> fit theta = a + b*f   (a single emitter is exactly linear)
        |         |
        |         v
        |    residual rms  --->  "wobble"  (alarm if > ~5 deg)
        |
   per-bin power P_k  ->  |FFT|  ->  cepstrum
        |
        v
   peak at delay d = argmax, ratio = peak / median P_k
        |                                     (alarm if ratio >= 5)
        v
   "a second, coherent path exists; its extra delay is d"
```

Measured, 50 MHz emitter at 10° and a repeater at 40°, equal power, 16 trials:

| delay | fused azimuth | bias | wobble rms | cepstrum peak |
|---|---|---|---|---|
| none | 10.01° | +0.01° | **0.31°** | noise (ratio 2) |
| 20 ns | 6.53° | −3.47° | 41.2° | 21 ns (ratio 7) |
| 50 ns | 15.83° | +5.83° | 31.5° | 49 ns (ratio 10) |
| 100 ns | 5.72° | −4.28° | **43.8°** | 101 ns (ratio 11) |
| 200 ns | 6.57° | −3.43° | 41.2° | 201 ns (ratio 9) |

The unambiguous delay is set by the bin width, 1/(2·bin):

| front end | bin width | unambiguous delay |
|---|---|---|
| 1024-band channelizer (shipped) | 1.953 MHz | 256 ns |
| 4096-point transform | 488 kHz | 1024 ns |
| 16384-point transform | 122 kHz | 4097 ns |

**Result:** a repeater is *detected* with certainty and its delay is measured to
1 %; the direction is **not** usable (the fused DOA is 3–6° wrong, and the alarm
says so). **Fails when** the emitter fills ≤ 1 bin (no ripple, no wobble) or the
delay is zero.

## 6. Algorithm D — two-path ML: get both directions back

§5 says *a second path exists and here is its delay*. That delay is what makes
the pair separable on four elements, because it fixes how the relative phase
changes **across the band** — the dimension four elements do not have.

```
 per-bin data X_k (snapshots x 4)
        |
        v
 covariance R_k -> dominant eigenvector v_k   (phase-referenced to element 0)
        |
        +--> P_k(az)      = a(az,f_k)^H v_k                  (bins x angles)
        +--> G_k(az1,az2) = a(az1,f_k)^H a(az2,f_k)          (bins x ang x ang)
        |
        v
 for every (|g|, phase) hypothesis and the measured delay tau:
        c_k = g * exp(-j 2 pi (f_k - f_c) tau)        <-- tau sets the SLOPE
        model_k = a(az1) + c_k a(az2)
        statistic = SUM_k |model_k^H v_k|^2 / |model_k|^2
        (vectorised over all angle pairs: ~0.15 s per hypothesis, 26 bins)
        |
        v
 argmax -> theta_source, theta_decoy, |g|
```

### 6.1 Result with the delay known

| array | delay given | path 1 | path 2 | both < 3° |
|---|---|---|---|---|
| 2×2 @ 30 mm | true | 8.0° | 37.0° | **100 %** |
| 3×3 @ 30 mm | true | 8.0° | 37.0° | 100 % |

Four elements are enough because 26 bins of frequency diversity substitute for
elements.

### 6.2 How accurate the delay has to be

| bandwidth | bins | delay error 0.5 ns | delay error 5 ns |
|---|---|---|---|
| 1 MHz | 1 | 0 % | 6 % |
| 5 MHz | 3 | **100 %** | 100 % |
| 20 MHz | 10 | **100 %** | 0 % |
| 50 MHz | 26 | **100 %** | 0 % |

Tolerance ≈ 1/(10·bandwidth). §7 shows a radar handing you half a nanosecond
from the leading edge of its own pulse.

### 6.3 The blind search is the weaker option

42 delay hypotheses (0–300 ns at 10 ns, then ±10 ns at 2 ns), delay unknown:

| bandwidth | bins | delay found | path 1 / 2 | both < 3° |
|---|---|---|---|---|
| 1 MHz | 1 | 0 ns | 17.5° / 29.0° | **0 %** |
| 5 MHz | 3 | 117 ns | 9.8° / 35.0° | 25 % |
| 20 MHz | 10 | 100 ns | 8.0° / 37.0° | **100 %** |
| 50 MHz | 26 | 100 ns | 8.0° / 37.0° | **100 %** |

The statistic is not comparable across delay hypotheses, so the search over-fits.
**Measure the delay; do not search it.**

### 6.4 The modelling error that cost a round

The first version used a real `g`: the whole relative phase was `2π f_k τ`. It
recovered both directions only when `τ` was exact and collapsed at 0.1 ns (12/32°
instead of 8/37°), because 0.1 ns at 2.5 GHz is 1.57 rad of constant phase the
model could not absorb. Physically the decoy's chain adds that phase itself, so
the correct model searches it (complex `g`) and lets `τ` set only the slope. The
old numbers were reported before the fix; they are superseded by 6.1–6.3.

**Fails when** the emitter fills one bin (no frequency diversity at all, measured
0 %), when the delay is wrong by more than 1/(10·bandwidth), or when there are
more than two paths.

## 7. Algorithm E — the radar case: time ordering

A radar transmits to work. A decoy cannot repeat what it has not received, so:

```
   arrival(direct)   = R / c
   arrival(repeat)   = (R_radar-decoy + R_decoy-array)/c + tau_turnaround
                     >= R / c + tau_turnaround          (triangle inequality)
```

**This is geometry, not a signal property.** No waveform, no power level and no
Doppler shift can reverse it. Radar at 5 km, decoy at range r:

| decoy position | path (m) | repeat arrives after the direct path by |
|---|---|---|
| on the axis, 500 m out | 5 000 | τ (path excess 0) |
| on the axis, 2 000 m out | 5 000 | τ (0) |
| 60° off-axis, 1 000 m | 5 583 | 2 043 ns |
| 90° off-axis, 300 m | 5 309 | 1 131 ns |

A 100 ns turnaround is **200 samples at 2 GS/s** — 500× finer than the 256 ns
minimum delay the 1024-band channelizer can see (§5).

### 7.1 The timeline

```
 radar pulse   |############ 1 us ############|
 direct path   |#############################|          radar alone here
 repeat (+tau) |          |#############################|
               ^          ^                             ^
               |          |                             |
         leading edge     |                        pulse ends
         W >= 20 ns       |                             |
         radar only       |---- both paths overlap -----|
                          |                             |
                          v                             v
                    comparison window            tail, length = tau
                    (this is where the            decoy alone: its own
                     whole-pulse method           DOA, and tau measured
                     is 12-16 deg wrong)          directly
```

### 7.2 Rung A — the leading-edge gate

```
 raw samples (4 ch)
        |
        v
 +------------------+     +-------------------------------+     +---------+
 | envelope detector|---->| edge time (threshold, or the  |---->| window  |
 | sum |x|^2 / M    |     | steepest rise on a capture)   |     | [e,e+W) |
 +------------------+     +-------------------------------+     +---------+
                                                                     |
                                                                     v
                                                    covariance over W x pulses
                                                    -> dominant vector -> DOA at
                                                       the window's instantaneous
                                                       frequency (waveform-aware)
```

Azimuth error in degrees, coherent repeater 30° away, equal power, 0 dB per
sample, 1 µs LFM, 2×2 at 30 mm, 8 trials:

| delay | whole pulse (§5/§6 method) | gate W = τ/2 | gate W = τ | gate W = 2τ |
|---|---|---|---|---|
| 20 ns | 14.08 | 0.79 | **0.41** | 9.14 |
| 50 ns | 15.76 | 0.40 | **0.22** | 9.52 |
| 100 ns | 12.28 | 0.47 | **0.29** | 9.22 |
| 200 ns | 15.49 | 0.16 | **0.09** | 9.17 |

Over-running to W = 2τ lets the repeat in and the error returns to ~9°: the gate
must stay inside the decoy's dead time. With ±2 ns of error on the edge position
the 100 ns gate measures 0.22°.

How much window is enough (RMSE in degrees, delay 100 ns):

| per-sample SNR | W = 5 ns | 10 ns | 20 ns | 50 ns | 100 ns |
|---|---|---|---|---|---|
| −10 dB | 6.61 | 4.45 | 2.89 | 2.20 | 2.46 |
| 0 dB | 1.56 | 0.91 | 0.52 | 0.49 | 0.21 |
| +10 dB | 0.47 | 0.37 | 0.21 | 0.20 | 0.12 |

### 7.3 Rung B — the tail

```
        pulse ends here
              |
   ...########|#####|##############|
              |     ^              ^
              |     |              |
              |   tail start    tail end (= start + tau)
              |
              +-- everything after this point is the decoy alone:
                  its DOA directly, and tau = tail length
```

| delay | tail length | tail DOA | error (truth 40°) |
|---|---|---|---|
| 20 ns | 20 ns | 39.3° | 0.67° |
| 50 ns | 50 ns | 39.4° | 0.59° |
| 100 ns | 100 ns | 39.6° | 0.41° |
| 200 ns | 200 ns | 39.4° | 0.59° |

One record, two answers, no model: the radar at 10° during its own pulse and the
decoy at 40° for 100 ns afterwards.

### 7.4 A Doppler pull-off changes neither

| DRFM Doppler shift | whole pulse | gate W = 100 ns |
|---|---|---|
| 0 kHz | 13.08° | 0.19° |
| 100 kHz | 13.22° | 0.36° |
| 1 MHz | 14.09° | 0.32° |

### 7.5 The gate does not depend on the waveform

1 µs pulses, W = 100 ns from a 50 %-amplitude edge, 0 dB per sample, 8 trials:

| waveform | whole pulse | gate | tail DOA (truth 40°) | tail length |
|---|---|---|---|---|
| LFM 50 MHz | 12.28° | 0.39° | 40.0° | 100 ns |
| LFM, 20 ns raised-cosine edge | 12.32° | 0.37° | 40.0° | 100 ns |
| tan-FM (non-linear chirp) 50 MHz | 12.66° | 0.12° | 40.0° | 100 ns |
| Barker-13 phase code | 7.80° | 0.24° | 40.0° | 100 ns |

A phase code has no instantaneous-frequency sweep at all and the gate still
holds: what the gate needs is a decoy-free *time slice*, not a modulation.

### 7.6 Calibration residual, and how short the window can be

±0.5 dB and ±5° per channel (the V07 §11.3 residual), 0 dB per sample, 16 trials:

| waveform | window | no calibration error | with residual |
|---|---|---|---|
| LFM 50 MHz | 10 ns | 0.91° | 3.20° |
| LFM 50 MHz | 20 ns | 0.53° | 2.03° |
| LFM 50 MHz | 50 ns | 0.34° | 1.84° |
| LFM 50 MHz | 100 ns | 0.20° | 1.61° |
| Barker-13 | 10 ns | 0.82° | 2.06° |
| Barker-13 | 20 ns | 0.77° | 2.73° |
| Barker-13 | 50 ns | 0.36° | 1.87° |
| Barker-13 | 100 ns | 0.16° | 2.29° |

Read the two columns together: without calibration error the gate is a
noise-limited estimate; the residual puts a bias floor of about **1.9°** on top,
the same order as the 0.79° that 0.5 mm of geometry error costs (V07 §11.3). The
gate measures the radar correctly; **calibration, not the decoy, is what remains
between it and the 0.5° class.** A 10 ns window is noise-limited at ~3°, which is
a dwell choice, not a limit of the method.

### 7.7 Where the radar case fails

* **Continuous-wave source** — no leading edge, no tail. §3–§6 are then all that
  exists, with the limits measured there.
* **A decoy that does not have to hear the pulse** (a look-alike waveform
  replayed from a library on its own schedule) breaks the ordering; it is then an
  independent co-channel source and §4 applies: 0.4 of 2 on the 2×2.
* **A weak direct path** — at −10 dB per sample a 20 ns window is 2.9°, and the
  edge detector itself needs the direct path visible per sample (~+10 dB, see
  §11).
* **A pulse shorter than the decoy's turnaround** — the ordering still holds, but
  the tail may be longer than the pulse; that is fine for the tail, and the gate
  is shorter than the pulse, so accuracy degrades as in the −10 dB row.

## 8. The master flow

```
 raw 2 GS/s complex, 4 channels, from the RFDC
        |
        v
 [A] channelizer (1024 bins) + power clustering, floor = 25th percentile
        |
        v
   is there a pulse edge?  ------------------- no ------------------+
        | yes                                                      |
        v                                                          v
 [E] leading-edge gate: W = min(tau, 100 ns)             [B] per-bin DOA of the
     -> radar DOA  (0.09-0.79 deg)                            priority cluster
 [E] tail after the pulse:                               [C] wobble + cepstrum
     -> decoy DOA + tau   (0.4-0.7 deg)                       |
        |                                                     +-- flat -> report DOA
        |                                                     |
        |                                      wobble/ripple --+
        |                                                     |
        |                                                     v
        |                                        [D] two-path ML with the
        |                                            measured delay tau
        |                                                     |
        +-------------------------+---------------------------+
                                  v
                  two directions + a confidence flag, to the
                  PS tracker, with the operator's priority
                  target (runtime choice, not a hardware mode)
```

A Mermaid version of the same flow is in
[`decoy-flow.mmd`](decoy-flow.mmd).

## 10. What is impossible on this hardware

| Decoy | Separable? | Why not / what would be needed |
|---|---|---|
| own carrier | yes, free | — |
| independent, same carrier, ≥ 30° apart | not on 2×2 (0.4 of 2) | ≥ 3×3 (9 elements) |
| coherent repeater, CW source, ≥ 5 MHz | yes, if the delay is known | time-domain delay measurement or the blind search |
| coherent repeater, CW source, ≤ 1 MHz | **no direction** | more elements; one bin has no frequency diversity |
| coherent repeater, radar source | **yes** | a pulse and edge timing |
| co-located, zero delay, CW source | **no** | polarisation, PRF/waveform fingerprinting, or a second platform |
| co-located, zero delay, radar source | **yes** | the leading edge: the first τ ns are decoy-free |
| library waveform, own timing | no ordering | falls back to MUSIC: 9+ elements |

## 11. Gate G7 — the only thing left to prove

All of the above is host simulation. `scripts/radar_decoys.py --replay` is the
post-processing that gate G7 runs on a captured record `(pulses, samples, 4)`:

```bash
python3 scripts/radar_decoys.py --replay build/output/g7_capture.npy \
    --pulse-ns 1000 --delay-ns 100 --window-ns 100 \
    --truth-az 10 --decoy-az 40
```

Acceptance numbers, measured here and repeated in
[`GATES_RUNBOOK.md`](../GATES_RUNBOOK.md) §G7:

| criterion | threshold | measured (host) |
|---|---|---|
| leading-edge DOA error | < 1.5° | 0.09–0.79° |
| whole-pulse DOA error (must be visible) | > 5° | 7.8–15.8° |
| edge jitter ±2 ns | < 1.5° | 0.22° |
| Doppler pull-off 1 MHz | < 1.5° | 0.32° |
| tail DOA error | < 3° | 0.41–0.67° |
| gate, worst waveform | < 1.5° | 0.39° |
| gate at 100 ns with calibration residual | < 3° | 2.29° |

`make g7-selftest` runs the replay path itself on a synthetic capture (about two
seconds) and is part of `make verify-phase-interf`, so the post-processing G7b
will use is exercised on every host check rather than only on the bench.

A replay of a synthetic capture through the same path (16 pulses, +10 dB and 0 dB
per sample, delay 100 ns) gives: leading edge 9.75° / 10.05° for a source at 10°,
whole pulse 24.35° / 24.49° (the pull-off, as designed), tail 39.70° / 39.10° for
a decoy at 40° — `PASS` on all three criteria at both SNR levels.

**Prerequisites G7 must have, and why:** a bitstream from G4; two coherent RF
paths (radar emulator + repeater with a switched delay line of 100 ns and 500 ns);
the calibrated array and rotator from G6; and a direct path of at least ~+10 dB
per sample, because the edge detector is the one part of the chain that needs to
see the radar in a single sample. Everything else in §7 is measured down to 0 dB
per sample.

## 12. Reproduce

```bash
make decoy-df      # §3-§6  -> decoy_discrimination.txt   (~1 min)
make radar-decoy   # §7    -> radar_decoys.txt            (~3.5 min)
make lint          # static checks

python3 scripts/decoy_discrimination.py --quick     # ~5 s smoke run
python3 scripts/radar_decoys.py --quick             # ~75 s smoke run
python3 scripts/radar_decoys.py --replay capture.npy --pulse-ns 1000 \
        --delay-ns 100 --truth-az 10 --decoy-az 40  # gate G7 post-processing
```

Both scripts need python3 + numpy only, are seeded (`--seed`), and write a
`RESULT=PASS` footer that the Makefile targets propagate.
