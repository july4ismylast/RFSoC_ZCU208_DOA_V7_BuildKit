WHY 16K AT 2 GSPS DOES NOT BUY ACCURACY (equal observation time)
Angular variance for a coherent cross-spectrum measurement is set by the
number of coherently combined bin-snapshot products, not by FFT length:

  sigma_theta ~ c / (2*pi*f_c*d) * sigma_phi / sqrt(K),  K = bins x snapshots

front end                          bins in 50 MHz frames/8.2us            K
1024-band channelizer                    25.6      16.02          410
4K FFT                                  102.4       4.00          410
16K FFT                                 409.6       1.00          410

So 1024 bands x 16 frames and 16K x 1 frame both give K ~ 410 for a 50 MHz
emitter: the same angular accuracy for the same integration time.  Finer bins
matter for separating emitters that are close together inside the band, not
for the angle of a single emitter.
