VERDICT
  The ladder is not a setting on one algorithm, it is the algorithm.
  Each index is applied to the cells the previous one left, and the
  first index that splits a cell is the one that decided it:
   1. different modulation -> the label splits the cell (100% of frames
      with the label alone, 0% with direction alone).
   2. same modulation, different direction -> direction splits it (100%
      with direction alone, 0% with the label alone).
   3. same modulation, same direction -> nothing may split it: one cell is
      the correct answer (1.00 cells per frame, 100% of frames right).
   4. ... unless one of them is a repeater: the cell stays one cell and
      the ripple flags it -- 97% with the verification index, 0%
      without it. A verification index adjudicates a cell; it never
      splits one.
  The general policy is that ladder in that order, verification last:
  mod -> direction -> bandwidth -> cadence -> cepstrum. It is also a CLI
  argument: --policy replaces the ladder and V7 shows what it costs.

  Order matters where the label is wrong: at 0 dB 'mod' is chance, so a
  mod-first ladder cannot split anything (V6, first column) while a
  direction-first ladder still can. That is why the label is trained and
  voted (§18) before it is trusted in the first position.
